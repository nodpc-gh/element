## 🛠️ Технологии

### Написано на **FASM** (Flat Assembler)

**Весь проект создан на ассемблере!**

| Компонент | Технология |
|-----------|------------|
| **Веб-сервер** | FASM x86 Assembly |
| **Сокеты** | Win32 API (ws2_32.dll) |
| **HTTP** | Ручная реализация |
| **Frontend** | HTML5/CSS3/JavaScript |

### Почему FASM?

- ⚡ **Скорость** — нативный машинный код
- 📦 **Размер** — весь сервер ~285 КБ
- 🎯 **Контроль** — полная работа с памятью
- 🏛️ **Классика** — дань уважения низкоуровневому программированию

### Статистика кода

```
src/main.asm    ~200 строк  (веб-сервер, сокеты)
src/html.inc    ~250 строк  (HTML/CSS/JS интерфейс)
──────────────────────────────────────
Итого:          ~450 строк  ассемблера
```

### Сборка

```batch
fasm src\main.asm output\element.exe
```

**Результат:**
- `element.exe` — самодостаточный веб-сервер
- Не требует библиотек
- Не требует установки
- Запускается сразу

## 📖 Описание

Element IDE — это легковесная веб-IDE для визуального проектирования потоков данных и событий. Позволяет перетаскивать элементы на рабочую область, соединять их портами и экспортировать проект в JSON.

**Особенности:**
- 🎨 Визуальный редактор с сеткой
- 📦 Палитра UI элементов (Button, Label, Edit, CheckBox, Panel)
- 🔴 Порты на 4 сторонах элемента (in, out, id, data)
- 🔗 Соединения между портами с цветовой индикацией
- 📋 Копирование элементов
- ⚙️ Компилятор в JSON
- 🖱️ Контекстные меню для управления

## 🚀 Быстрый старт

### Установка

1. Скачайте репозиторий:
```bash
git clone https://github.com/YOUR_USERNAME/Element.git
cd Element
```

2. Откройте `output\element.exe` или соберите из исходников:
```batch
fasm src\main.asm output\element.exe
```

### Запуск

```batch
output\element.exe
```

Сервер запустится на порту **8080**. Откройте в браузере:
```
http://localhost:8080
```

**Важно:** Нажмите `Ctrl+Shift+R` для полной перезагрузки страницы (очистка кэша)!

## 📖 Использование

### Создание элементов

1. Перетащите элемент из левой панели на рабочую область
2. Перемещайте элемент перетаскиванием
3. Двойной клик → удалить элемент

### Управление портами

**Правый клик на элементе:**
- **+ (зелёный)** — добавить порт на сторону
- **− (красный)** — удалить порт со стороны
- **📋 Копировать** — создать копию элемента со смещением
- **🗑️ Удалить** — удалить элемент

### Соединения

1. Кликните на любом порту (кружок на границе элемента)
2. Потяните к другому порту (пунктирная линия следует за мышью)
3. Кликните на целевом порту → соединение создано

**Типы соединений (цвета):**
- 🟢 **Зелёный** (data) — путь данных
- 🟣 **Фиолетовый** (event) — события
- 🟠 **Оранжевый пунктир** (id) — идентификация

**Правило:** В один порт — только одно соединение!

### Контекстные меню

| Объект | Меню |
|--------|------|
| **Элемент** | Управление портами (+/−), Копировать, Удалить |
| **Порт** | Удалить порт |
| **Линия** | Удалить соединение, Показать тип |

### Компилятор (JSON экспорт)

Нажмите **⚙️** в toolbar для экспорта проекта:

```json
{
  "version": "1.0",
  "elements": [
    {
      "id": "el_1",
      "type": "btn",
      "caption": "Button",
      "x": 100,
      "y": 150,
      "ev": 0,
      "ports": [
        {"pos": "pl", "type": "in"},
        {"pos": "pr", "type": "out"},
        {"pos": "pt", "type": "id"},
        {"pos": "pb", "type": "data"}
      ]
    }
  ],
  "connections": [
    {"from": "out", "to": "in", "type": "event"}
  ]
}
```

**Кнопки экспорта:**
- **📋 Копировать JSON** — в буфер обмена
- **💾 Скачать файл** — сохранить `element_project.json`

## 🔧 Технические детали

### Стек технологий

- **FASM 1.73.32** — Flat Assembler
- **Win32 API** — сокеты (WSAStartup, socket, bind, listen, accept, recv, send)
- **Порт** — 8080 (0x901F в little endian)
- **HTML5/CSS3/JavaScript** — интерфейс IDE

```batch
"D:\Programms\IDE\FASM\FASM.EXE" src\main.asm output\element.exe
```

```batch
start /B output\element.exe

taskkill /F /IM element.exe
```
