## 🛠️ Технологии

### Написано на **FASM** (Flat Assembler) + **JavaScript**

**Сервер на ассемблере, интерфейс на чистом JS!**

| Компонент | Технология |
|-----------|------------|
| **Веб-сервер** | FASM x86 Assembly (модульная архитектура) |
| **Сокеты** | Win32 API (ws2_32.dll) |
| **HTTP** | Ручная реализация |
| **API** | REST (>/api/projects, /api/save-project) |
| **База данных** | Файловая (DBM-формат) |
| **Frontend** | HTML5/CSS3/JavaScript (чистый JS, без библиотек) |
| **Подсветка кода** | Кастомная (FASM-синтаксис) |

### Почему FASM?

- ⚡ **Скорость** — нативный машинный код
- 📦 **Размер** — весь сервер ~285 КБ
- 🎯 **Контроль** — полная работа с памятью
- 🏛️ **Классика** — дань уважения низкоуровневому программированию

### Статистика кода

```
src_v2/            ~1200 строк  ассемблера (9 модулей)
output/www/         ~2000 строк  JavaScript (8 модулей)
output/www/          ~400 строк  CSS
──────────────────────────────────────
Итого:             ~3600 строк  кода
```

### Сборка

```batch
"D:\Programms\IDE\FASM\FASM.EXE" src_v2\main_server.asm output\element.exe
```

**Результат:**
- `element.exe` — самодостаточный веб-сервер с REST API
- Встроенный браузер html/css/js — все в одном exe
- Не требует библиотек / установки
- Автоматически открывает браузер при запуске

## 📖 Описание

Element IDE — это легковесная веб-IDE для визуального проектирования потоков данных и событий. Сервер написан на **FASM** (чистый ассемблер), интерфейс — на чистом **JavaScript** без фреймворков.

**Особенности:**
- 🎨 Визуальный редактор с сеткой (Drag&Drop)
- 📦 Палитра UI элементов (Button, Label, Edit, CheckBox, Panel)
- 🔴 Порты на 4 сторонах элемента (in, out, id, data)
- 🔗 Соединения между портами с цветовой индикацией
- 📋 Копирование/вставка элементов
- ⚙️ Компилятор в JSON с буфером обмена и скачиванием
- 🖱️ Контекстные меню для управления
- 🐚 **Активная консоль** — все действия логируются в формате `$ cmd args`
- 🤖 **Элемент OpenCode** — AI-агент с терминальным стилем
- 📝 **Редактор кода** с подсветкой FASM-синтаксиса
- 🗄️ **База данных** элементов (просмотр/поиск/фильтрация)
- 💾 **Сохранение/загрузка** проектов через REST API
- 🔌 **Панель портов** с описанием назначения каждого порта

## 🚀 Быстрый старт

### Установка

1. Скачайте репозиторий:
```bash
git clone https://gitverse.ru/nodpc/element.git
cd element
```

2. Соберите сервер (требуется [FASM](https://flatassembler.net/)):
```batch
build
```

3. Или запустите готовый бинарник:
```batch
output\element.exe
```

Сервер запустится на порту **8080** и автоматически откроет браузер:
```
http://localhost:8080
```

## 📖 Использование

### Создание элементов

1. Перетащите элемент из левой панели на рабочую область
2. Перемещайте элемент перетаскиванием
3. Двойной клик → удалить элемент

### Управление портами

**Правый клик на элементе:**
- **+ (зелёный)** — добавить порт на сторону
- **− (красный)** — удалить порт со стороны
- **📋 Копировать** — создать копию элемента со смещением
- **🗑️ Удалить** — удалить элемент

### Соединения

1. Кликните на любом порту (кружок на границе элемента)
2. Потяните к другому порту (пунктирная линия следует за мышью)
3. Кликните на целевом порту → соединение создано

**Типы соединений (цвета):**
- 🟢 **Зелёный** (data) — путь данных
- 🟣 **Фиолетовый** (event) — события
- 🟠 **Оранжевый пунктир** (id) — идентификация

**Правило:** В один порт — только одно соединение!

### Контекстные меню

| Объект | Меню |
|--------|------|
| **Элемент** | Управление портами (+/−), Копировать, Удалить |
| **Порт** | Удалить порт |
| **Линия** | Удалить соединение, Показать тип |

### Консоль

Все действия с элементами отображаются в нижней панели **Консоль** в формате команды:

```
[14:32:05] $ mkEl btn el_5 at (100, 200)
[14:32:07] $ conn port_a -> port_b (event)
[14:32:10] $ delEl el_5 removed
[14:32:15] $ compile 3 elements, 2 connections
```

### Компилятор (JSON экспорт)

Нажмите **⚙️** в toolbar для экспорта проекта:

```json
{
  "version": "2.0",
  "elements": [...],
  "connections": [...]
}
```

**Кнопки экспорта:**
- **📋 Копировать JSON** — в буфер обмена
- **💾 Скачать файл** — сохранить `element_project.json`

### Сохранение проекта

Проекты сохраняются на сервер через REST API:
- **💾 Save** — сохранение текущего проекта
- **📂 Загрузить** — выбор и загрузка проекта из списка

### Панель свойств

Правая панель отображает свойства выделенного элемента:
- **Элемент** — имя, позиция, размер
- **Данные** — тип, ID
- **Статистика** — количество событий
- **Код** — редактор кода элемента (с подсветкой FASM)
- **🔌 Порты** — список портов с описанием и статусом соединения

## 🔧 Технические детали

### Сервер (FASM)

- **FASM** — Flat Assembler
- **Win32 API** — сокеты (ws2_32.dll), файловый ввод-вывод (kernel32.dll), печать/оболочка (shell32.dll)
- **Порт** — 8080
- **Многопоточность** — accept-цикл с последовательной обработкой
- **API** — REST-like: GET /api/projects, GET /api/projects/{id}, POST /api/save-project
- **Автооткрытие браузера** — ShellExecuteA при старте

### Frontend (JS)

- Чистый JavaScript ES5 — без фреймворков и библиотек
- **Модули:** компилятор, консоль, редактор кода, база данных
- **Консоль:** cmd() — формат командной оболочки с timestamp
- **Подсветка:** кастомный парсер FASM-синтаксиса (комментарии, строки, ключевые слова)
- **Совместимость** — Chrome/Edge/Firefox

### Сборка

```batch
build
```

Или вручную:
```batch
"D:\Programms\IDE\FASM\FASM.EXE" src_v2\main_server.asm output\element.exe
```

### Команды

```batch
# Сборка
build

# Запуск
start /B output\element.exe

# Проверка
tasklist | findstr element
netstat -ano | findstr :8080

# Остановка
stop

# Статус
status
```
